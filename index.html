Lost

Ein Kind, allein in einem Wald, den die Welt vergessen hat. Kahle Bäume, Nebel, Stille – bis kleine Begegnungen ihn Schritt für Schritt wecken.

Auf dem Steam Deck installieren

  1. In den Desktop-Modus wechseln (Steam-Taste → Ein/Aus → Zum Desktop wechseln).
  2. Das Paket für das Steam Deck oben herunterladen und im Dateimanager (Dolphin) per Rechtsklick → Entpacken in einen Ordner wie /home/deck/Games entpacken.
  3. Steam öffnen → Spiele → Ein Nicht-Steam-Spiel zu meiner Bibliothek hinzufügen … → Durchsuchen … → Dateityp Alle Dateien → lost.sh im entpackten Ordner wählen.
  4. Zurück in den Spielmodus: Lost steht in der Bibliothek unter Nicht-Steam. Gesteuert wird mit dem Gamepad.

Ruckelt es? In den Startoptionen des Spiels LW_QUALITY=medium %command% (oder low) eintragen.

Windows und macOS

Windows: ZIP entpacken, lost.exe starten. Meldet SmartScreen „Der Computer wurde durch Windows geschützt“: Weitere Informationen → Trotzdem ausführen.

macOS: ZIP öffnen, Lost.app in den Ordner Programme ziehen. Beim ersten Start Systemeinstellungen → Datenschutz & Sicherheit → bei „Lost“ Dennoch öffnen.
